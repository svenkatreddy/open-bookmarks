open-bookmarks

Status: 1.0 Draft, not yet published. Breaking changes are still allowed before the 1.0 publication.

A simple, open format for sharing bookmark packs. A pack is a JSON file with folders and links. Anyone can write one, host it anywhere, and share it by URL. No account, no server, no lock-in.

A folder can hold links directly, or it can point at another pack with a source URL. Importing takes a snapshot. Remote packs only change your copy when you refresh on purpose. Only http and https links are allowed, and remote sources must use https.

Example pack

{
  "format": "open-bookmarks/1.0",
  "title": "News",
  "nodes": [
    {
      "type": "folder",
      "title": "World",
      "nodes": [
        { "type": "url", "title": "BBC News", "url": "https://www.bbc.com/news" }
      ]
    }
  ]
}
